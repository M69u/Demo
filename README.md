# Demo
This is a demo project for getting familiar with the GitHub platform. Feel free to explore the repository and check out the README.md file for more information.

List of git commands:
- `git init`: Initializes a new Git repository.
- `git add <file>`: Stages changes to be committed.
- `git commit -m "message"`: Commits staged changes with a message.
- `git status`: Shows the status of changes in the repository.
```bash
# Example of using git commands
git init
git add index.html
git commit -m "Add index.html file"
git add index.css
git commit -m "Add index.css file"
git status
```
This project includes an `index.html` file that serves as the main webpage and an `index.css` file for styling. The HTML file contains a simple structure with a heading and a paragraph, while the CSS file applies basic styling to the body of the webpage.
